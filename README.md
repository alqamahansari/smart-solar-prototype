# Smart Solar Energy Prototype

This project is a smart renewable energy prototype designed to analyze environmental and grid-related data for improving solar energy utilization and intelligent energy decision-making.

The system integrates weather intelligence, automation workflows, and data-driven analysis to explore practical applications of smart energy management and sustainable technology systems.


## Project Overview

The prototype focuses on combining real-time environmental data with intelligent monitoring workflows to support smarter solar energy usage and renewable energy awareness.

### The system includes:

- Weather data integration using OpenWeather API
- Grid and environmental data analysis
- Automated scheduling workflows
- Backend processing using Python and Flask
- Smart energy monitoring concepts
- Renewable energy analytics exploration

The project reflects the growing importance of intelligent and sustainable energy systems capable of supporting large-scale renewable energy adoption and smart infrastructure development.

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/alqamahansari/smart-solar-prototype.git
cd smart-solar-prototype
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Create a `.env` file and add your API keys:

```env
OPENWEATHER_API_KEY=your_api_key
```

### 4. Run the Application

```bash
python app.py
```
